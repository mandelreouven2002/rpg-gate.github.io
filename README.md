# שער להרפתקה

הבית של משחקי התפקידים בישראל: קבוצות, כנסים, חנויות וחוגים על מפה אחת, מדריכים לכל שיטת משחק, מאמרים, ופינת מתחילים לשחקנים חדשים ולהורים.

האתר: https://gate.roleplay.top

## מבנה האתר

| קובץ | מה הוא |
|---|---|
| `index.html` | דף הבית: השער, העולמות האדומים והכחולים |
| `search.html` | פורטל החיפוש עם מפת האזורים |
| `next-con.html` | מתי הכנס הבא? לוח כנסים לפי חודש |
| `quiz.html` | שאלון: איזה משחק מתאים לי. השאלות, הניקוד והתוצאות נמצאים ב-`quizData` בתוך `data.json` |
| `catalog/` | קטלוג משחקי התפקידים בעברית: `catalog.json` (המוצרים, המחירים והקישורים לחנויות), `thumbnails/` (הכריכות), ועמודים שנבנים אוטומטית: הקטלוג ועמוד לכל מוצר. קישורי DriveThruRPG מקבלים את מזהה השותף אוטומטית |
| `privacy.html` | תצהיר ופרטיות: מעמד הפרויקט (אישי והתנדבותי), Google Analytics ושיתוף ניתוחים מסוכמים, עוגיות ושירותים חיצוניים. מקושר מהפוטר. כשמוסיפים כלי שאוסף מידע, מעדכנים אותו ואת התאריך |
| `donate.html` | דף התרומות: פייפאל, ו-bit או PayBox. מקושר מהפוטר |
| `updates.html` | הרשמה לעדכונים: מעביר אוטומטית לערוץ הוואטסאפ `msg.roleplay.top` |
| `articles/` | המאמרים, עמוד המאמרים ועמוד שיטת המשחק |
| `404.html` | עמוד "חדר ריק במבוך" |
| `data.json` | כל הנתונים: ארגונים, כנסים, חנויות, חוגים, אזורים, שיטות ועדכונים |
| `static/articles/files/`, `articles/files/` | מדריכי השיטות בפורמט Markdown (המקור) |
| `articles/systems/` | עמוד HTML לכל שיטה, נבנה אוטומטית מקבצי ה-Markdown |
| `llms.txt`, `llms-full.txt`, `agents.json` | קבצים למנועי חיפוש מבוססי בינה מלאכותית. `llms-full.txt` נבנה אוטומטית |
| `static/photos/` | התמונות של "מה זה משחקי תפקידים" |

כל עמוד עומד בפני עצמו: העיצוב כתוב בתוך הקובץ, ואין תלות ב-CSS חיצוני.

כל הקישורים הפנימיים יחסיים, כך שהאתר עובד גם בדומיין משלו (`gate.roleplay.top`) וגם בכתובת של גיטהאב עם תת-תיקייה (למשל `username.github.io/repo-name/`). כשמוסיפים עמוד או קישור חדש, כותבים את הנתיב בלי `/` בהתחלה ועם `.html` בסוף: `search.html` מעמוד בשורש, ו-`../search.html` מעמוד בתוך `articles`. ככה האתר עובד גם כשפותחים את הקבצים ישירות מהמחשב.

## איך מעדכנים תוכן

רוב התוכן נמצא ב-`data.json`. מוסיפים או משנים שם ארגון, כנס, חנות או חוג, והאתר מציג את השינוי מיד.

כדי שגוגל ותצוגות קישור יראו גם את השינוי, התוכן נכתב לתוך קבצי ה-HTML על ידי הסקריפט:

```
pip install markdown
python3 scripts/prerender.py
```

הסקריפט גם בונה עמוד לכל שיטה בתיקייה `articles/systems` מתוך קבצי ה-Markdown, מעדכן את מפת האתר ואת `llms.txt`, וכותב את `llms-full.txt`. כדי להוסיף שיטה חדשה, שמים קובץ Markdown בשתי תיקיות המדריכים ומריצים את הסקריפט.

ה-Action שבקובץ `.github/workflows/prerender.yml` מריץ את הסקריפט אוטומטית בכל שינוי ב-`data.json`, וגם פעם בחודש כדי לעדכן את "הכנס הבא". כדי שהוא יוכל לשמור את השינויים, צריך לאפשר לו כתיבה: Settings, Actions, General, ואז Workflow permissions: Read and write.

## בדיקה מהמחשב

האתר עובד גם כשפותחים את הקבצים ישירות, אבל חלק מהנתונים מתעדכנים רק דרך שרת, כי דפדפנים לא מאפשרים לדף שנפתח מהדיסק לטעון קבצים אחרים. בתיקיית האתר מריצים:

```
python3 -m http.server
```

ונכנסים ל-`http://localhost:8000`. הקישורים באתר מתאימים את עצמם אוטומטית גם לשרת המקומי.

## העלאה לגיטהאב פייג'ס

1. מעלים את כל הקבצים לשורש של ריפו חדש, כולל התיקיות `.github` ו-`static`, והקובץ `.nojekyll`.
2. ב-Settings, Pages, בוחרים Deploy from a branch, הענף `main` והתיקייה `/ (root)`.
3. הקובץ `CNAME` מחבר את האתר לדומיין `gate.roleplay.top`. דומיין יכול להיות מחובר לריפו אחד בלבד, אז צריך להסיר אותו מהריפו הישן לפני שהחדש יקבל אותו. אם הריפו החדש הוא לבדיקה בלבד, מוחקים את `CNAME` ממנו.
